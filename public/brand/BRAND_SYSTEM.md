# GPOST Strategy Brand System

This downloadable guide accompanies the interactive `/brand` page.

## Modes

- **Light:** current-state continuity; white/cloud canvas, ink text, cobalt actions, restrained geographic detail.
- **Dark:** future-state strategy; midnight/navy canvas, cobalt structure, lime progress signals, geographic systems as the signature motif.

## Core tokens

- Midnight `#071522`
- Strategy Navy `#10233A`
- GPOST Cobalt `#1767F2`
- Signal Cyan `#18A9CF`
- Progress Lime `#B8D930`
- Warm Paper `#F4F1EA`
- Cloud `#F7FAFF`
- Ink `#101D2F`

## Type

- Display: Georgia or compatible editorial serif.
- Interface/body: Arial, Helvetica, or compatible neutral sans serif.
- Use compact sentence-case headlines and tracked uppercase eyebrows.

## Page sequence

1. Orient with shared header, theme, section number, and executive headline.
2. Frame one thesis and classify evidence as Verified, Interpretation, or Hypothesis.
3. Make one relationship visible: flow, hierarchy, comparison, timeline, or scorecard.
4. End with decisions, owners, measures, risks, or next steps.

## Asset rules

Use the supplied GPOST references without recoloring, stretching, rotating, retyping, or adding effects. Confirm original production trademark files with GPOST before external commercial use.

Use geographic imagery only when place, routing, networks, local relevance, or global operations are materially part of the message.

## Quality checklist

- Reuse shared components and CSS tokens.
- Reserve lime for progress or the recommended path.
- Link verified public claims to authoritative sources.
- Check mobile stacking, keyboard behavior, contrast, alt text, and reduced-motion behavior.
- Run a production build before publishing.
